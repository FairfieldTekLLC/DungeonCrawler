# Dungeon Crawler Game

Build a complete dungeon crawler game in C# using MonoGame.

## Technical Requirements

- C# .NET 10
- MonoGame
- Visual Studio solution
- Runs on Windows
- Keyboard controls
- Graphical display
- Get real images for the monsters
- not a web application

## Game Features

### Player

- WASD movement
- Health
- Mana
- Leveling system
- Inventory

### Combat

- Melee attacks
- Magic attacks
- Damage calculation
- Critical hits

### Enemies

- Goblins
- Skeletons
- Orcs
- Boss monsters

### Dungeon System

- Procedurally generated dungeon
- Multiple floors
- Rooms connected by corridors
- Fog of war

### Loot

- Weapons
- Armor
- Potions
- Gold

### UI

- Main menu
- Character stats
- Inventory screen
- Health and mana bars
- Minimap

### Save System

- Save game
- Load game
- Multiple save slots

## Quality Requirements

- No compile errors
- Organized project structure
- README.md included
- XML comments on public methods
- Separate game systems into classes

## Completion Criteria

The project is complete only when:

- Solution builds successfully
- Player can explore dungeons
- Combat works
- Loot drops work
- Multiple dungeon levels exist
- Save/load works
- README documentation exists
- make your str_replace tool call chunk is smaller and ensure you include all required parameters.
